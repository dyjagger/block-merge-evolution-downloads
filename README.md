# Block Merge Evolution — Android builds

This repository hosts signed Android test builds for Block Merge Evolution.

Download the current build:

<https://github.com/dyjagger/block-merge-evolution-downloads/releases/latest/download/block-merge-evolution-debug.apk>

Release assets are published here so the APK can be downloaded from any
internet connection. Android may ask you to allow installs from your browser
or from Block Merge Evolution; that is expected for these private test builds.
